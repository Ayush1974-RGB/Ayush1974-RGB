## Featured Project
# 🤖 Featured Project — PredictX AI Portal

> A full-stack AI-powered prediction platform featuring real-time machine learning modules for gold price prediction, fraud detection, spam classification, and rainfall forecasting.

PredictX AI Portal is a complete Flask + React machine learning web application built from the ground up. Every module — from authentication and API architecture to ML model integration and frontend dashboards — was independently designed, implemented, and deployed.

---

## ⚙️ Technical Highlights

| System | Details |
|--------|---------|
| Authentication | Secure JWT-based signup, login, and session verification |
| Backend API | Flask REST API with modular route architecture |
| Frontend | React-based responsive UI with protected routes and dashboard system |
| Gold Prediction | Gradient Boosting model predicting Indian gold prices with 99.96% R² accuracy |
| Fraud Detection | Random Forest classifier detecting fraudulent transactions with 99.8% accuracy |
| Spam Detection | TF-IDF + Logistic Regression pipeline for spam email classification |
| Rainfall Prediction | Random Forest model for rainfall forecasting |
| ML Pipeline | Automated training system generating `.pkl` models dynamically |
| API Integration | Axios-powered frontend/backend communication with proxy handling |
| Deployment Ready | Configured for Render (backend) and Vercel (frontend) deployment |
